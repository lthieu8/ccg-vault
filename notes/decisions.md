# Decisions Log

Cross-cutting answers that outlive a single feature. Feature-specific Q&A belongs in that
feature's spec under `## Decisions`.

**Append-only.** Never edit or delete an entry — if an answer changes, add a new entry that
supersedes it and say so. The history is what lets you work out why something was built the way
it was.
